# Modern Clear Frame package

Production catalog and AR front: `front.png`. Real normalized parts: `left-temple.png` and `right-temple.png`. All three contain exactly the same bytes as the previously verified legacy cutouts. No regenerated temple artwork is used.

`product.json` explicitly adopts existing Product 2 and persists its complete measured fit profile. Both temples and the front use the existing head-local rigid assembly, curved ribbons, measured lens apertures, face/head depth and tracking smoothing. No database ID selects geometry.

`modern-clear-front.webp`, `modern-clear-side.webp`, `modern-clear-3q.webp` and the original `modern-clear-left-temple.png` / `modern-clear-right-temple.png` are retained as provenance for the opt-in extraction/calibration tools. They are not alternate catalog products. Running sync never processes or modifies these assets.
